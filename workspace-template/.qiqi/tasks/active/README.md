# Active Tasks

Giữ task còn đang thực hiện, còn blocker, còn verification chưa đạt hoặc còn khả
năng tiếp tục theo UAT.

Tạo file mới từ `../TEMPLATE.md`. Chỉ cập nhật state có giá trị qua nhiều lượt:
scope, decision, dependency, terminal milestone/outcome, verification, native
`session_id`, `result_path` và blocker. Không ghi working transcript, live child
state hoặc progress polling.
