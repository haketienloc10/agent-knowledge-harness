# Repository Decisions

Thư mục này lưu quyết định kỹ thuật lâu bền thuộc riêng repository hiện tại và
các trade-off cần được giữ để agent không thiết kế lại cùng vấn đề khi chưa có
bằng chứng mới.

Chỉ tạo tài liệu khi quyết định đã được chấp nhận hoặc đã được implementation,
test hay approval xác nhận.

Mỗi tài liệu nên nêu rõ:

- bối cảnh;
- quyết định;
- lý do và trade-off;
- hệ quả;
- phương án đã loại bỏ nếu cần;
- evidence hoặc approval;
- điều kiện xem xét lại.

Không dùng thư mục này làm log thảo luận, execution plan hoặc nơi ghi quyết định
ảnh hưởng nhiều repository.
